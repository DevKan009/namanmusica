# Naman Musica — Official Landing Page

Official artist landing page for **Naman Musica** featuring interactive Web Audio synth, responsive visuals lookbook, vinyl music player, tour dates, and newsletter subscription.

## 🎵 Features

- **Interactive Audio Player**: Built-in generative lo-fi/indie ambient synthesizer using the Web Audio API, real-time timer, progress bar, and spinning vinyl record.
- **Visuals Lookbook**: Staggered cards for *Red Room*, *Golden Hour*, *Wild Card*, and *After Dark* with interactive modal previews.
- **Dual Crossing Marquees**: Angled kinetic marquee banners with infinite scrolling.
- **Responsive Design**: Mobile-optimized layouts including a compact 2-column lookbook grid and mobile hamburger drawer.
- **Signature Brand Aesthetic**: Distinctive custom palette with signature color `#e34234` across buttons, badges, and accents.
- **Tour Schedule & Newsletter**: Tour listing and front-row newsletter signup.

## 🚀 Getting Started

Serve locally with any static server:

```bash
# Using Python
python -m http.server 3000

# Or using Node / npm
npm start
```

Open `http://localhost:3000` or open `index.html` directly in your browser.
